# Rock Paper Scissors

A console-based Rock Paper Scissors game built as part of [The Odin Project](https://www.theodinproject.com/) JavaScript curriculum.

## Live Demo
 https://nightfury18-cyber.github.io/The-Odin-Project---Rock-Paper-Scissors/

## How to Play

1. Open `index.html` in your browser.
2. Open the browser's developer console (F12 or right-click → Inspect → Console).
3. You'll be prompted to enter your choice: **Rock**, **Paper**, or **Scissors**.
4. The game runs for 5 rounds. After each round, the winner is announced in the console.
5. At the end, your final score and the overall winner are displayed.

## Features

- Randomized computer choice each round
- Case-insensitive player input (e.g. "rock", "ROCK", and "Rock" all work)
- Score tracking across 5 rounds
- Final result summary at the end of the game
